## Правила

- Имена файлов скриншотов в тексте описания не повторять: они видны во вложениях и в ссылках «скриншот».

- Раздела «Контекст» и отдельной строки «Учётная запись» нет: роль и логин — первый пункт «Предусловий».
- «Источник» — в самом низу, после горизонтальной линии `---`.
- «Доказательства» — таблица в одну колонку на белом фоне, серая шапка «Доказательства»; первая строка — пояснение про красную рамку, далее по строке на каждый снимок: подпись и `{{collapse(скриншот) !имя.png! }}` в одной строке (проверено на #120843).
- Таблица шагов — на белом фоне: строка `table{background:#ffffff}.` прямо над шапкой таблицы (карточка задачи в Redmine жёлтая, весь фон описания из текста не перекрасить; проверено на #120843).
- Ячейка «Фактический результат» в строке с ошибкой заливается `{background:#fdecec}.` (проверяется на #120765; если Redmine заливку не покажет — убрать).

- Шаги, ожидаемый и фактический результат — одной таблицей; отдельных разделов «Фактический/Ожидаемый результат» нет.
- В описании нет адреса стенда и раздела «Окружение прогона» (браузер, Playwright, viewport). Адрес — только в поле «Адрес страницы».
- Дата и время наблюдения — только в разделе «Источник».
- Скриншот — вложением (POST /uploads.json → token); в описании картинка свёрнута под ссылку «скриншот» в строке таблицы «Доказательства»: `{{collapse(скриншот) !имя.png! }}`. Превью `{{thumbnail}}` не использовать. Пути к локальным файлам не писать.
- Текстовый снимок страницы (DOM .txt) не прикладывать и не упоминать.
- Дубли искать по локальной базе `/Users/ifinance/Documents/FACT/Redmine/redmine_issues_base.json`; перед поиском обновить её дельтой: `node /Users/ifinance/Documents/FACT/Redmine/import_20261022/redmine_adapter.js sync` (подгружает только задачи с updated_on после прошлой сверки). Полную выгрузку не повторять.
- Точный дубль (в т. ч. закрытый) → задачу не создавать, сообщить пользователю.
- Связанные задачи — только в поле Redmine «Связанные задачи» (API relations); в описании раздела «Связанные задачи» нет (v6).
  - Типы: «связана с» (relates) — близкая задача, обратная ситуация, общая причина; «дублирует» (duplicates) — только когда лишнюю задачу закрываем как дубль; «блокирует»/«предшествует» — только если исправление одной задачи нужно для другой.
