## 2. Вердикт

Код панели держит права там, где это обещано для первого выпуска панели: единый резолвер доступа к проекту с отказом по умолчанию, одна проверка границ пути для файлов, загрузок, скачивания, вложений и статики, файрвол инструментов с отказом при любой ошибке, окружение подпроцессов по белому списку с тест-стражем, ключ базы знаний и токены личных подключений в процессе панели, а не в аргументах claude. Пилот `42` построен так, как записан: семь инструментов, только они при включённой лупе, эхо ключа в ответе отклоняется, редиректы и прокси из окружения выключены.

Дыр три уровня.

1. **Один пользователь ОС на всё** (`29` §2 п. 3 остаётся главным). Любая ограниченная сессия с полным доступом к проекту без bwrap обходит файрвол за два шага: `Write` скрипта в проект и `Bash python3 файл.py`; скрипт читает `.env` (0640, группа сервиса) и `/proc/<pid>/environ` панели, то есть `WEB_JWT_SECRET`, и подделывает cookie администратора (У43-01, критично, открыто). `claude.require_jail` по умолчанию `false`, установщик только предупреждает. Привилегированная сессия получает то же без обхода (У43-02, критично, известно).
2. **Код, который верит пустому секрету или чужому хосту**: вход Telegram при пустом токене бота подделывается (У43-03, высоко при веб-установке с белым списком); ключ Redmine уходит на хост редиректа и по `http` (У43-05); терминал SSH не проверяет ключ хоста (У43-06); шифр токена Redmine выведен из `WEB_JWT_SECRET` (У43-07).
3. **База данных как два мира**: DDL чат-базы живёт в трёх местах (рантайм, ORM, Alembic) и они расходятся (Б43-01, Б43-02); таблицы разных хранилищ ссылаются друг на друга без внешних ключей, удаление пользователя оставляет его шифрованные ключи и членства (Б43-03, У43-08); проект имеет две личности, путь в чат-базе и `id` в офисе (Б43-04).

Строить дальше можно. До выката пилота `42` на прод обязательны У43-01 (`require_jail: true` и проверка bwrap на EC2), У43-03 (404 при пустом токене), У43-05, У43-06. Остальное по срезам B и 138-141, как уже записано в `29` и `00` §6. Семнадцать путей, одиннадцать дыр базы, двенадцать расхождений, четыре вопроса.

## 8. Вердикт

Панель держит то, что обещала для одного доверенного круга: границы путей, белый список окружения, файрвол с отказом при ошибке, ключи вне аргументов и вне сессии модели.
