**Требования:** G128
**Blocked by:** нет
**Зона:** `src/connections/`, `src/claude/bridge.py` (запасной транспорт), `tests/connections/`
**Волна:** вне срезов
**Status:** done

## Что должно заработать

Пользователь подключает GitHub или Notion в «Подключениях», и инструменты работают в чате как раньше. Расшифрованный токен остаётся в памяти процесса Платформы. Его нет в аргументах процесса claude, во временном файле запасного транспорта и в окружении сессии модели. Платформа работает посредником (proxy): принимает вызов инструмента от модели и сама передаёт его сервису с токеном.

## Из брифа, дословно

## Критерии приёмки

- [x] Тестовый токен не встречается ни в одном аргументе команды claude для GitHub и Notion
- [x] Временный файл запасного транспорта не содержит токен
- [x] Посредник получает список инструментов и вызывает их у сервиса, неверный заголовок отклоняется
- [x] Окружение процесса Notion собрано из белого списка плюс `NOTION_TOKEN`
- [x] Ошибки и журнал не содержат токен
- [x] Новых падений тестов нет
