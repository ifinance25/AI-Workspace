# 198 — Вход проектной команды через Telegram без прав владельца

**Требования:** вне манифеста, слово пользователя 2026-10-31
**Blocked by:** нет
**Зона:** `src/web/`, `src/office/storage.py`, `src/bot/`, `web/src/`
**Волна:** вне срезов
**Status:** done

## Что должно заработать

Участник команды привязывает Telegram к своей учётке в настройках и входит либо паролем, либо через Telegram. Его права не меняются. Посторонний через бота ничего не получает.

## Из брифа, дословно

> «нужны оба варианта - вход через Телеграм удобен и сразу в наличии привязка к его аккаунта и возможность получать уведомления от Платформы»

## Критерии приёмки

- [x] Привязка: одноразовый код на 10 минут, в базе только хэш, подтверждение паролем с лимитером
- [x] Вход виджетом и `/weblogin` открывает локальную учётку, сессия несёт `tv`
- [x] Посторонний получает 403, строка `users` не появляется
- [x] Админ и выключенная учётка через Telegram не входят
- [x] Участник не получает прав белого списка (тест-страж)
- [x] Вне белого списка бот понимает только `/start bind_<код>` и `/weblogin` в личном чате
- [x] Отвязка, сброс пароля и удаление учётки снимают доступ
- [x] Новых падений тестов нет
